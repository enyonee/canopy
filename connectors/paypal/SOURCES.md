References: [PayPal Orders v2](https://developer.paypal.com/api/orders/v2), [Payments v2](https://developer.paypal.com/api/payments/v2), and [server SDK (PayPal SDK License)](https://github.com/paypal/PayPal-TypeScript-Server-SDK/tree/b02a9b9c8f53418d6278928fa41b174803037277). Implemented from the HTTP contracts; no SDK code is distributed.

This is a one-time, no-shipping CAPTURE order with one purchase unit. A payer redirect does not confirm payment. After approval, capture once via the outbox and read the capture; reconcile the order reference, amount, currency and COMPLETED capture status before fulfillment. A PENDING refund is not complete; read the refund. Do not create a replacement operation to resolve an ambiguous outcome; query its provider state first. The live host is production. The default sandbox is offline, not a PayPal sandbox account.
