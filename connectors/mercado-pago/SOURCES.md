References: [official Node SDK, MIT](https://github.com/mercadopago/sdk-nodejs/tree/cdfecc30344d6e567c6b1b3b77d766339882b863), [Checkout Pro preferences](https://www.mercadopago.com.br/developers/en/reference/online-payments/checkout-pro-preferences/overview), and [payment refunds](https://www.mercadopago.com.br/developers/en/reference/online-payments/checkout-pro/create-refund/post).

Use the merchant application `accessToken`. The checkout preference ID is not a payment ID. Use the return's payment ID only as a lookup hint; authenticate the read, compare the provider payment ID, merchant order reference, currency and amount against the immutable order, and only then accept `approved`. Use exact decimal normalization in the accounting layer; the preference API amounts are JSON numbers. Refunds are read by payment ID and refund ID. The descriptor does not trust a redirect's status.
