References: [official Node API library, MIT](https://github.com/Adyen/adyen-node-api-library/tree/1c3c3bfeaf83bbbeb0c58e6dab03fc75f62439ec), [Pay by Link](https://docs.adyen.com/unified-commerce/pay-by-link/create-payment-links/api/), and [live endpoint formats](https://docs.adyen.com/development-resources/live-endpoints/).

Set `endpointPrefix` to the account's full live URL prefix (including any merchant suffix), `merchantAccount`, `countryCode`, and API key in `apiKey`. This descriptor creates and reads single-use links. `completed` is the payment-link state, not proof of capture. For fulfillment or refunds verify payment and capture in Adyen, use the payment PSP reference, and reconcile the refund using Adyen's verified webhook or Customer Area. `received` is acceptance only; this descriptor does not receive Standard webhooks.
