# Тесты рантайма

Гейт из плана: пока рантайм не доказан, любая цифра эксперимента мерит мои баги, а не язык.

```bash
node --test 'tests/*.test.mjs'                                              # прогон
node --experimental-test-coverage --test-coverage-exclude='tests/**' \
     --test-coverage-exclude='verify/**' --test 'tests/*.test.mjs'         # покрытие
node tests/mutate.mjs                                                       # мутационный гейт
node tests/mutate.mjs "money"                                               # только мутации с этим словом в имени
node verify/run.mjs                                                         # приёмочные проверки всех приложений
```

Зависимостей нет: `node:test`, `node:assert`, встроенное покрытие Node 22. Исходящий HTTP в
тестах подменён (`fakeFetch` в `tests/helpers.mjs`): записывает вызовы и отвечает тем, что
скажет тест.

## Покрытие

146 тестов. По строкам и функциям — 100 % во всех одиннадцати модулях рантайма
(`auth`, `blocks`, `cli`, `expr`, `outbox`, `patch`, `render`, `server`, `spec`, `store`,
`validate`). По ветвям — от 96 до 100 %: непокрытые ветви — это дефолты деструктуризации и
`?.` на значениях, которые чекер не пропускает.

Полное покрытие получилось не только тестами: там, где ветка оказалась недостижимой
(`|| []` при массиве, который гарантирует чекер; `default:` в `switch` по узлам, которые
строит только парсер), правильный ответ — убрать мёртвый код, а не писать тест на него.
Так исчезло шесть защитных заглушек в первой версии и ещё пять «невозможных» `throw` во второй.

## Мутационный гейт

Покрытие говорит «строка исполнилась». Гейт говорит «тесты заметили бы, будь она неверной».
`tests/mutate.mjs` вносит в рантайм по одной осмысленной поломке и требует, чтобы прогон покраснел.

Первые четыре мутации — это ровно те четыре дефекта, которые нашли первые одиннадцать
приложений: они обязаны ловиться навсегда. Вторая половина списка — то, что делает
формат v2 опасным, если сломать молча: неверный пароль пускает, поддельная сессия принимается,
`own` не проверяется, список показывает чужие строки, скачивание файла без прав, правило не
срабатывает, уникальность сталкивается с самой строкой, переход игнорирует статус или роль,
поля перехода необязательны, отказ блока коммитит сделанное до него, ящик не сбрасывается
после коммита, не-2xx считается доставкой, деньги хранятся в мажорных единицах или читаются в
минорных, `gte` значит `gt`, месяц группируется по дню, хеш попадает на страницу, чекер
пропускает недостижимый статус, неизвестную операцию, цикл, плохое выражение, неизвестный
узел или ссылку.

**Что гейт нашёл в этот раз.** При 100 % покрытия строк выжили четыре мутации из 75, и
каждая — дыра в утверждениях, а не в исполнении: (1) `by` у перехода не проверялось на
странице — кнопка предлагалась, а сервер отказывал; тест смотрел только на сервер;
(2) приоритет умножения над сложением исполнялся, но не утверждался; (3) `gte` против `gt`
не различался, потому что ни один тест не бил точно в границу; (4) пароль в колонке никогда
не проверялся — вместо теста на маскирование чекер теперь запрещает пароль в колонках, а
ветка рендера удалена. Плюс двенадцать старых мутаций перестали накладываться после
переписки рантайма — их образцы обновлены, все двенадцать по-прежнему убиваются.

Текущий результат: **81 из 81 мутаций убито** (последние семь добавлены под дефекты, которые нашёл второй раунд бенча: подмена строки после `db.createRow`, потеря flash на форме, ложный цикл в агрегате, `@me.поле`, `own` в связанной таблице, отказ внутри события). Это и есть содержательная часть покрытия —
проценты сами по себе не значат ничего.
