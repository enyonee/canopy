# Тесты рантайма

Гейт из плана: пока рантайм не доказан, любая цифра эксперимента мерит мои баги, а не язык.

```bash
node --test 'tests/*.test.mjs'                                              # прогон
node --experimental-test-coverage --test-coverage-exclude='tests/**' \
     --test 'tests/*.test.mjs'                                              # покрытие
node tests/mutate.mjs                                                       # мутационный гейт
node verify/run.mjs                                                         # приёмочные проверки 11 приложений
```

Зависимостей нет: `node:test`, `node:assert`, встроенное покрытие Node 22.

## Что чем покрыто

| файл | о чём тесты |
|---|---|
| `spec.test.mjs` | разбор объявлений полей, умолчания, приведение типов — граница, на которой жили три из четырёх найденных дефектов |
| `store.test.mjs` | схема из графа, миграции и досев, идемпотентность, удалённое поле, запросы, агрегаты |
| `validate.test.mjs` | каждая ветка чекера: путь ошибки, текст, подсказка; плюс проверка, что все 11 графов остаются валидными |
| `blocks.test.mjs` | каждый блок каталога поимённо, включая веса и регистронезависимую сверку ответа |
| `server.test.mjs` | маршруты, валидация формы, события, действия, связанные разделы, списки, панели, отказы и трасса |
| `render.test.mjs` | экранирование, темы, множественное число, все виды полей формы, панели и страницы |
| `patch.test.mjs` | правки по узлам, экранированные сегменты, отказ применить патч, ломающий граф |
| `cli.test.mjs` | `--check`, запуск, невалидный граф, свои пути к базе и трассе |
| `props.test.mjs` | свойства, а не примеры: любой валидный граф поднимается; миграция идемпотентна; рост графа не теряет строк; форма и блок дают одно значение; трасса воспроизводима |
| `edges.test.mjs` | защитные ветки: пустые сущности, отсутствующие объявления, нулевые веса, неразрешимые ссылки |

Полное покрытие получилось не только тестами: там, где ветка оказалась недостижимой
(`|| []` при массиве, который гарантирует чекер), правильный ответ — убрать мёртвый код,
а не писать тест на него. Так исчезло шесть защитных заглушек.

## Мутационный гейт

Покрытие говорит «строка исполнилась». Гейт говорит «тесты заметили бы, будь она неверной».
`tests/mutate.mjs` вносит в рантайм по одной осмысленной поломке и требует, чтобы прогон покраснел.

Первые четыре мутации — это ровно те четыре дефекта, которые нашли приложения: они обязаны
ловиться навсегда.

**Что гейт нашёл сразу:** при 100% покрытия мутация «снятая галочка на создании падает в
объявленное умолчание» **выжила** — то есть третий из реальных дефектов не был проверен ничем.
Покрытие показывало зелёное, потому что строка исполнялась в каждом прогоне; утверждения о ней
не было. Дыра закрыта отдельным тестом (`an unchecked box means false, even when the declared
default says true`), где у поля объявлено `bool=true`, а форма его не присылает.

Текущий результат: **29 из 29 мутаций убито**. Это и есть содержательная часть покрытия —
проценты сами по себе не значат ничего.
